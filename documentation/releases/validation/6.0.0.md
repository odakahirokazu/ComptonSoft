# 6.0.0 release validation

Validated on 2026-11-17, macOS arm64, Apple Clang 21.0.0, CMake 4.4.5,
ANL Next 3.0.1, Ruby 4.0.9, ROOT 6.40.04 and Geant4 11.4.3.
Ruby, GDML and FITS IO were enabled; Python, Qt visualization, HEALPix,
ONNX Runtime and HSQuickLook were disabled for this build.

The release was built from `6.a.16` plus the fixes listed in the
[release notes](../6.0.0.md), without migration-prototype libraries or bindings.
Build and installation completed successfully.

## Results

The unchanged standard Ruby examples and their complete databases were used.
The smoke runner only overrides event count, batch size, seed, thread count,
output location and, for IO tests, output/raw mode. Seed: 10; batch: 200 events.

| Case | ANL events | Geant4 threads | Result |
| --- | ---: | ---: | --- |
| pixel_detector | 1,000 | 1 | 618 hits / 618 detected events |
| stacked_pixel_detectors | 1,000 | 1 | 113 hits / 93 detected events |
| strip_detector | 1,000 | 1 | 623 hits / 241 detected events |
| pixel_detector, MT | 1,000 | 2 | 618 hits / 618 detected events |
| pixel eventtree | 1,001 | 1 | 619 hits / 382 empty events; all 1,001 IDs in order |
| pixel raw eventtree | 1,001 | 1 | 2,892 deposits / 364 empty events; all IDs in order |
| Input without initial information | 32 | — | Both writers preserve counts; no `ini_*` or `weight` branches invented |
| FITS image output and independent CFITSIO readback | 22 frames | — | Dimensions, every pixel's energy and count match the ROOT input |

The raw test checks that local and world deposit positions agree within 1e-6 cm
for the pixel example's identity placement. This exercises the `MakeRawHits`
initialization fix. The no-initial-info test retains and checks run/event IDs and
hit counts (22 hits) after removing only initial-particle branches from the input.
The 1,001-event cases generate six Geant4 batches (1,200 events) and consume only
1,001 events, checking the partially consumed final batch explicitly.

These are execution and data-contract checks, not a complete detector-physics
validation. Hardware data from each legacy reader, all reconstruction modes,
optional libraries, Linux and Python were not exercised in this release check.

## Reproduction

Use the `6.0.0` checkout and the Ruby executable matching its bindings. Set the
library search path to this installation (on Linux, use `LD_LIBRARY_PATH` instead
of `DYLD_LIBRARY_PATH`). ROOT and CFITSIO development files must be available.
Run from the checkout root and use a new output directory.

```sh
export CS_PREFIX=/path/to/comptonsoft-6.0.0-install
export DYLD_LIBRARY_PATH="$CS_PREFIX/lib${DYLD_LIBRARY_PATH:+:$DYLD_LIBRARY_PATH}"
export CHECK_OUTPUT=/path/to/new-validation-directory
mkdir "$CHECK_OUTPUT"

ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/run_example.rb pixel_detector "$CHECK_OUTPUT/pixel.root"
ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/run_example.rb stacked_pixel_detectors "$CHECK_OUTPUT/stacked.root"
ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/run_example.rb strip_detector "$CHECK_OUTPUT/strip.root"
ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/run_example.rb pixel_detector "$CHECK_OUTPUT/pixel_mt.root" 1000 2
ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/run_example.rb pixel_detector "$CHECK_OUTPUT/eventtree.root" 1001 1 eventtree
ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/run_example.rb pixel_detector "$CHECK_OUTPUT/raw.root" 1001 1 raw

root -l -b -q "tests/release_smoke/remove_initial_info.C(\"$CHECK_OUTPUT/eventtree.root\",\"$CHECK_OUTPUT/no_initial_info.root\")"
ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/rewrite_without_initial_info.rb "$CHECK_OUTPUT/no_initial_info.root" "$CHECK_OUTPUT/rewritten.root"
root -l -b -q "tests/release_smoke/check_trees.C(\"$CHECK_OUTPUT\")"

ruby -I "$CS_PREFIX/lib/ruby" tests/release_smoke/make_fits.rb "$CHECK_OUTPUT/no_initial_info.root" "$CHECK_OUTPUT/frame"
c++ tests/release_smoke/check_fits.cc $(root-config --cflags --libs) $(pkg-config --cflags --libs cfitsio) -o "$CHECK_OUTPUT/check_fits"
"$CHECK_OUTPUT/check_fits" "$CHECK_OUTPUT/no_initial_info.root" "$CHECK_OUTPUT/frame"
```

Each simulation writes its applied ANL parameters alongside the ROOT file.
The checks fail on lost/duplicated event IDs, incorrect counts or raw positions,
invented initial information, and inconsistent FITS images.
