# Compton Soft 6.0.0

Release date: 2026-11-17

This is the stable release of the existing detector framework with ANL Next 3
support. It provides a maintained baseline before the DetectorSystem redesign
planned for Compton Soft 7. The source and examples in the `6.0.0` tag are the
reference for that migration; fixes to this series belong on `maintenance/6.x`.

## Changes

- Complete the ANL Next 3 API and Ruby binding migration from the 6.a series.
- Retain the anlgeant4 execution model, existing detector models, configuration
  files, Ruby applications, and hit/event tree formats.
- Fix `MakeRawHits` initialization so that raw energy-deposit positions are not
  replaced by reconstructed positions of undefined pixels.
- Make `WriteHitTree` and `WriteEventTree` respect the presence of initial
  particle information. Rewriting data without that information no longer
  creates artificial `ini_*` and `weight` branches; run/event IDs are retained.

The release is based on `6.a.16`. Subsequent obsolete-module reorganization and
DetectorSystem migration prototypes are not included in this release.

## Requirements and compatibility

ANL Next 3, C++17, CMake 3.30 or later, ROOT and Geant4 are required.
See the [installation guide](../installation.md) for dependencies and options.
The existing XML and ROOT formats remain in use. This release does not introduce
the new detector-description library, libxml2 dependency, or prototype output
trees. Version 5.28.1 remains available for ANL Next 2 installations.
